# Historia 6 — Consultar historial de pedidos

**ID:** HU-06

Historia de usuario:

Como cliente, quiero consultar mis pedidos anteriores para revisar las compras que he realizado.

Criterios de aceptación:

- El usuario puede acceder a la sección de historial.
- El sistema muestra la lista de pedidos realizados.
- Cada pedido incluye fecha, productos y total pagado.
- El usuario puede visualizar el detalle de cada pedido.
