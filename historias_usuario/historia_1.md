# Historia 1 — Registro de usuario

**ID:** HU-01

Historia de usuario:

Como cliente de LePetitDep, quiero registrarme con mi correo electrónico y una contraseña para poder crear una cuenta y realizar pedidos.

Criterios de aceptación:

- El usuario puede ingresar correo electrónico y contraseña.
- El sistema valida que el correo tenga un formato correcto.
- El sistema verifica que el correo no esté registrado previamente.
- Al completar el registro correctamente, se crea la cuenta y se muestra un mensaje de confirmación.
