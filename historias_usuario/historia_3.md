# Historia 3 — Explorar menú

**ID:** HU-03

Historia de usuario:

Como cliente, quiero visualizar el menú de cafés y productos de panadería para conocer las opciones disponibles antes de realizar una compra.

Criterios de aceptación:

- El sistema muestra todos los productos disponibles.
- Cada producto incluye nombre, descripción y precio.
- El usuario puede desplazarse por el listado de productos.
- La información se muestra de forma clara y ordenada.
