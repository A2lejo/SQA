# Historia 5 — Realizar pedido

**ID:** HU-05

Historia de usuario:

Como cliente, quiero confirmar mi pedido y seleccionar un método de pago para completar la compra y recibir un número de orden.

Criterios de aceptación:

- El sistema muestra el resumen del pedido.
- El usuario puede seleccionar un método de pago simulado.
- El sistema solicita confirmación antes de finalizar.
- Al confirmar, se genera un número de orden único.
